# 시작하기

처음 쓰는 사람용. 5분이면 끝난다.

## 1. Node 설치 확인

```bash
node -v
```

`v20` 이상이면 된다. 없으면 [nodejs.org](https://nodejs.org)에서 LTS를 받는다.

## 2. Fish Audio API 키 발급

**무료다. 카드 등록도 필요 없다.**

1. [fish.audio/auth/signup](https://fish.audio/auth/signup) 에서 가입하고 이메일 인증
2. [fish.audio/app/api-keys](https://fish.audio/app/api-keys) 로 이동
3. **Create New Key** → 이름 아무거나 → **키를 복사** (이때만 보인다. 놓치면 새로 만들면 된다)

> **크레딧 충전은 안 해도 된다.** 이 도구는 기본 모델이 `s2.1-pro-free`이고,
> 그건 API 크레딧 0원에서도 호출된다. 다른 모델로 바꾸면 그때부터 충전이 필요하다.

## 3. 받아서 실행

```bash
git clone https://github.com/inkgun9794/fishaudio-morning-call.git
cd fishaudio-morning-call
cp .env.example .env
```

`.env`를 열어 `FISH_API_KEY=` 뒤에 **2번에서 복사한 키를 붙여넣는다.**

```
FISH_API_KEY=여기에_붙여넣기
```

그리고:

```bash
npm start
```

브라우저가 알아서 열린다. `npm install`은 필요 없다 — 외부 패키지를 하나도 안 쓴다.

터미널이 싫으면 폴더에서 더블클릭해도 된다.
Windows는 `모닝콜 스튜디오.cmd`, macOS는 `모닝콜 스튜디오.command`
(맥은 서명 없는 스크립트를 막으니 **처음 한 번만 우클릭 → 열기**)

## 4. 써보기

1. **대사를 쓴다** — "일어나. 벌써 일곱 시야."
2. **오른쪽에서 연기 지시를 고른다** — `달래듯` `버럭` `비꼬며` …
3. **▶ 미리듣기** — 바로 들린다
4. 마음에 들면 **＋ 단계 추가**로 07:10, 07:20 … 사다리를 만든다
5. 이름 적고 **저장** → **전체 굽기** → `out/` 폴더에 mp3

같은 대사에 지시만 바꿔서 들어보면 이 도구가 뭘 하는 건지 바로 안다.

## 5. 내 목소리로 만들기 (선택)

오른쪽 **목소리 추가**에서 `● 녹음`을 누르거나 파일을 올린다.
**10초 이상, 1~2분이 가장 좋다.** [`samples/대본.md`](../samples/대본.md)에 읽을 대본이 있다.

> **본인 목소리이거나, 동의를 받은 목소리만 올리세요.**
> 남의 목소리를 동의 없이 복제하는 건 대부분의 나라에서 문제가 되고,
> Fish Audio 약관도 금지합니다. 클론은 **당신의 API 키와 계정**으로 기록됩니다.

만들어지면 우상단 드롭다운에 바로 뜬다.

## 자주 막히는 곳

**`402 Insufficient API credit`**
→ 모델이 `s2.1-pro-free`가 아니다. `.env`의 `FISH_MODEL`을 확인한다.
Fish Audio는 웹앱의 *플랫폼 크레딧*과 API의 *API 크레딧*이 별개라, 웹에 잔액이 남아도 API는 막힌다.

**`FISH_API_KEY가 없습니다`**
→ `.env.example`이 아니라 `.env`에 넣었는지, `FISH_API_KEY=` 줄이 맞는지 확인한다.
(`FISH_REFERENCE_ID=`에 잘못 넣는 실수가 흔하다)

**여러 명이 동시에 쓰면 느리거나 막힌다**
→ 동시 요청 수 제한이 결제액 기준으로 걸린다 (Starter 5 / Elevated 15 / High Volume 50).
**키를 나눠 쓰지 말고 각자 발급받는 게 낫다.**

**클론한 목소리가 어색하다**
→ 샘플이 짧아서다. 10초짜리로는 `(버럭)` 같은 극단적인 지시에서 먼저 무너진다.
1~2분으로, **속삭임부터 외침까지 폭을 넣어** 다시 녹음하면 확 달라진다.

**마이크 녹음이 안 된다**
→ 브라우저 권한을 허용했는지 확인한다. `localhost`는 보안 컨텍스트라 http여도 마이크를 쓸 수 있다.
